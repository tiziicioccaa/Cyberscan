Glosario de ciberseguridad

Phishing
Engaño que intenta obtener información mediante mensajes o sitios falsos.
Malware
Software diseñado para realizar acciones dañinas o no autorizadas.
Ransomware
Tipo de malware que bloquea o cifra datos y exige un pago.
Hash
Resumen de longitud fija que permite verificar datos; no es cifrado reversible.
Autenticación multifactor
Verificación de identidad con dos o más factores distintos.
Vulnerabilidad
Debilidad que podría afectar la seguridad de un sistema.
